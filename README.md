# Football Talent — Scout & Career

Prototype 0.2.

## Экономика
- Стартовый бюджет: €100,000
- Скаутский отчёт: €5,000
- Тренировки имеют растущую стоимость
- Максимум 15 тренировок на игрока за сезон
- Рыночная стоимость рассчитывается из рейтинга, потенциала и возраста
- Продажа проходит вокруг реальной рыночной оценки, без огромного случайного множителя
- Прогресс сохраняется в браузере через localStorage

Все игроки в демо вымышлены.
