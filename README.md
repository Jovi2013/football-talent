# Football Talent — Scout & Career v0.4

Web-прототип футбольного менеджера/скаутского агентства.

## GitHub Pages
Загрузи `index.html` в корень репозитория и включи:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Игра работает как статический сайт. Прогресс сохраняется в localStorage браузера.
