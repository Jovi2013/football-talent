# ⚽ Football Talent: Scout & Career v0.6

## 🧑‍💼 Режим 1-го лица: менеджер + скаут + тренер

В v0.6 ты играешь не за одного футболиста — **ты руководишь всей футбольной карьерой агентства**.

Ты одновременно:
- 🔎 главный скаут;
- 🧑‍💼 менеджер;
- 🏋️ руководитель развития;
- 🤝 переговорщик;
- 💰 управляющий трансферами.

Цикл игры: **найти → оценить → развить → договориться → продать → расширить агентство**.

## 🛠️ Что исправлено в v0.6

- Исправлена ошибка `€NaN` в бюджете.
- Добавлена автоматическая проверка и восстановление повреждённых числовых сохранений.
- Стоимость игроков больше не меняется случайно при каждом обновлении экрана.
- Добавлены уровни скаута и тренера.
- Добавлена мораль агентства.
- Добавлен новый кабинет менеджера с решениями первого лица.
- Улучшен эффект тренировок в зависимости от уровня тренера.

## 📸 Реальные фотографии

В прототип добавлены фотографии реальных футболистов для справочных карточек.

Источники фотографий включают Wikimedia Commons. Для фотографий с лицензиями Creative Commons в интерфейсе указывается автор/лицензия. Например, фото Pedri на Wikimedia Commons указано как CC BY 4.0, а фотографии Kylian Mbappé и Jude Bellingham из WikiPortraits имеют лицензии Creative Commons с атрибуцией. 

Фото нужны для игрового интерфейса и не означают официального партнёрства с игроками или клубами.
